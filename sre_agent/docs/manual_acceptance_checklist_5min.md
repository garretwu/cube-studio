# 5 分钟人工验收清单（按页面打勾）

- 版本：2026-03-30
- 说明：本清单用于人工验收流程编排；当前步骤不要求拉起前后端。
- 使用方式：服务可用后按页面逐项勾选。

## 0. 验收前 30 秒

- [ ] 已确认使用 `sre_agent/docs/frontend_backend_contract_current.md` 作为唯一契约入口。
- [ ] 前端环境变量已明确（`proxy` 或 `direct` 二选一，不混用）。
- [ ] 测试账号 JWT 可用（Operator 或 Admin）。

## 1. 拓扑页面（约 90 秒）

- [ ] 页面标题为中文（AIDC 拓扑总览）。
- [ ] 首屏可看到实体数、关系数、活动告警三个指标卡。
- [ ] 状态区可看到 `Sync` 与 `WS` 状态，不出现英文占位标题。
- [ ] 若后端返回空数据，页面显示“请求成功但暂无数据”，不是 `Network Error`。
- [ ] 点击“手工刷新”后，状态从 `syncing` 回到 `ready/degraded/error` 之一。

## 2. 告警页面（约 60 秒）

- [ ] 页面标题与筛选控件为中文。
- [ ] 若无 firing 告警，显示业务空态文案而非错误。
- [ ] 若有告警，列表可加载并可选择一条用于诊断。
- [ ] WS 断开时有明确状态提示，不出现无提示空白。

## 3. 诊断页面（约 60 秒）

- [ ] 会话列表可加载（来自 `/api/sessions`）。
- [ ] 选中会话后可拉取 trace（`/api/sessions/{id}/trace`）。
- [ ] 若未触发会话，页面给出“先去告警页发起诊断”的引导。
- [ ] 不出现 `Diagnosis request failed` 与无解释的 `WS closed` 组合错误。

## 4. 对话页面（约 60 秒）

- [ ] 页面标题、输入框提示为中文。
- [ ] `/api/chat/history` 可加载历史消息。
- [ ] `/ws/chat` 可收到 `chunk` 与 `done` 事件。
- [ ] 若未配置 LLM key，提示文案明确且可定位（而非静默失败）。

## 5. 技能/知识页面（约 30 秒）

- [ ] 技能列表可加载（`/api/skills`）。
- [ ] 知识检索与文档列表接口返回可被页面消费。
- [ ] 接口失败时有“请求失败”文案，接口成功但空集时有“空态”文案。

## 6. 跨页联动（约 30 秒）

- [ ] 告警页触发诊断后，诊断页能看到新 session。
- [ ] 拓扑页 recent events 可观察到同步事件。
- [ ] 全流程中不出现跨域导致的 `Network/CORS error`。
